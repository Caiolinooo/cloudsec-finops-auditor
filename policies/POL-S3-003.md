# [POL-S3-003] Encryption at rest with SSE-KMS for regulated buckets

- **Severity:** HIGH
- **Framework:** SOC 2 CC6.7 · CIS AWS 2.1.1
- **Domain:** S3 / Encryption

## Clause

Buckets classified as customer-data, PCI, PII, or backup MUST use default
encryption `aws:kms` with a customer-managed CMK. SSE-S3 (`AES256`) alone is
insufficient for regulated data. Bucket keys should be enabled to reduce KMS
request cost.

A deny of `s3:PutObject` unless `s3:x-amz-server-side-encryption = aws:kms`
is required on those buckets.

## Remediation

1. Set bucket default encryption to SSE-KMS (CMK)
2. Enable S3 Bucket Keys
3. Add an encryption-enforcing bucket policy
4. Rotate the CMK per the crypto standard (annual or after personnel change)
