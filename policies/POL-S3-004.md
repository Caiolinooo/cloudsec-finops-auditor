# [POL-S3-004] S3 server access logging and object-lock for audit trails

- **Severity:** MEDIUM
- **Framework:** CIS AWS 3.6 · SOC 2 CC7.2
- **Domain:** S3 / Auditability

## Clause

Production buckets that accept customer uploads or hold audit evidence MUST
enable server access logging to a dedicated, non-public logging bucket in the
same region. Logging buckets SHOULD enable Object Lock (COMPLIANCE mode) for
the evidence retention period.

## Remediation

1. Enable server access logging (`PutBucketLogging`)
2. Restrict the log bucket with Block Public Access and SSE-KMS
3. Consider Object Lock for regulatory evidence
4. Alert on `DeleteBucket` / `PutBucketLogging` disable events
