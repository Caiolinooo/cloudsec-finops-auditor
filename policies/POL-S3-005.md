# [POL-S3-005] MFA Delete em buckets de backup e evidência

- **Severity:** HIGH
- **Framework:** CIS AWS 2.1.3 · SOC 2 CC7.2
- **Domain:** S3 / Retenção

## Clause

Buckets de backup, evidência de auditoria ou dumps de banco DEVEM ter
versionamento **e** MFA Delete. Apagar versão sem MFA é não conformidade.
Não substitui [POL-S3-002] (lifecycle); os dois se aplicam.

## Remediation

1. `VersioningConfiguration.MFADelete = Enabled` (chamada com root + MFA)
2. Negar `s3:DeleteObjectVersion` a papéis sem sessão MFA
3. Testar restore trimestral — retenção sem restore é teatro
